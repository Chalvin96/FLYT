# Components and interaction

Shared UI components own reusable primitives; pages own composition and domain copy. Preserve focus return, keyboard disclosure, accessible names, live announcements, and noninteractive loading skeletons. One transition must not be announced by both its visible status and a visually hidden live region.

Use direct, mature action/status copy. Distinguish loading, retryable failure, unavailable evaluation, success, and unknown destructive outcomes. Lesson and review render the same operation components; audio cleanup, write drafts, and retry state stay with those components. Reading and extension translation keep source tokens interactive for lookup.
