# Browser extension

The Manifest V3 service worker is stateless: it reads the host cookie at invocation time and forwards Bearer auth for authenticated mutations and optional-auth lemma detail. Anonymous dictionary resolution and search remain unauthenticated. The closed shadow root isolates arbitrary host pages. Content scripts use a cloned Readability document for page import; source URLs are retained for imports.

Selection invokes one native Translate action. Single words open lookup and multiword text opens translation; clicked source tokens can resolve lemmas without remounting the translation. Saving passes invocation-time sentence/title context, while source URL stays out of lemma context.

Popup composition owns placement, dismissal, focus, view state, latest-request guards, and liveness. Sentence, lemma results, search, and external actions may be separate cohesive views with explicit props; children never import the parent. Keep auth, import toast policy, privacy, and keyboard behavior intact.
